# Ecommerce Sales & Customer Insights Dashboard

### Capstone Project - Data Analytics Internship @ EduSkills Academy (8-Week Program)

This project is part of my 8-Week Data Analytics Internship with EduSkills Academy, focusing on E-commerce Sales and Customer behavior analysis.

#### 🔧 Tools & Technologies Used:
- **Python:** Pandas, NumPy, Matplotlib for Data Cleaning & EDA
- **SQL:** Advanced SQL for Data Extraction & Query Optimization
- **Power BI:** Interactive Dashboard & KPI Visualization
- **ETL Process:** Data Cleaning, Transformation, and Handling Missing Values

#### 📊 Key Insights & Dashboard Features:
- Sales Trend Analysis (Monthly/Quarterly)
- Customer Segmentation & Retention Insights
- Top-Selling Products & Categories
- Regional Sales Performance
- Revenue KPIs and Profit Margin

#### 📁 Project Structure:
- /data - Raw e-commerce dataset
- /notebooks - Python notebooks for EDA
- /sql - SQL queries used
- /dashboard - Power BI .pbix file & Screenshots
